  Goose used to be a command line tool. The arrival of a desktop application mostly changes the audience: you can now use it without being comfortable in a terminal.

  What stays the same:

  - The Apache-2.0 licence, so inspection and modification are free.
  - The extension model, which you enable as needed.
  - Model choice, including a local model through Ollama.

  For personal use, the cheapest combination remains a small local model for simple tasks and a free API for long reasoning.
