  Le catalogue s'élargit, ce qui rend l'outil pertinent pour deux choses :

  - **Comparer** le comportement de modèles concurrents sur le même prompt, dans la même interface.
  - **Prototyper** une intégration via une API compatible OpenAI, puis basculer vers un autre fournisseur pour la production.

body_en: |-
  GitHub Models remains one of the least demanding ways to try models from several vendors: no billing to enable, no credit card, just your GitHub account.

  The catalogue is widening, which makes the tool relevant for two things:

  - **Comparing** how competing models behave on the same prompt, in the same interface.
  - **Prototyping** an integration against an OpenAI-compatible API, then moving to another provider for production.

  The per-request and per-day limits remain the friction point: this is a testing ground, not a production platform.
